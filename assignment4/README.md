## Исходные данные

В `student_19.vcf` содержится 50 однонуклеотидных вариантов GRCh38: 6 на хромосоме 21 и 44 на хромосоме 22. Транзиций (A↔G, C↔T) - 38, трансверсий - 12.

## Аннотация

Аннотация выполнена для сборки GRCh38 с помощью VEP, ClinVar и gnomAD. В итоговую таблицу для каждого варианта включено наиболее тяжёлое последствие VEP. При одинаковой тяжести сначала выбирался MANE Select - представительный транскрипт, согласованный Ensembl и NCBI, затем canonical - основной по версии Ensembl, затем protein_coding - кодирующий белок. Если оставалось несколько транскриптов, выбирался первый по ID в лексикографическом порядке.

## Результаты

32 missense_variant, 16 synonymous_variant, один stop_gained и один splice_polypyrimidine_tract_variant. В ClinVar найдены 24 точных совпадения: 20 доброкачественных/вероятно доброкачественных, два неопределённой значимости, один конфликт и одна запись без классификации; 26 отсутствуют. gnomAD содержит все 50 вариантов, для одного нет экзомных данных.

## Три варианта

- **rs115673469 (ENTHD1)**. VEP: missense_variant, замена лейцина на серин (Leu427Ser). ClinVar: вероятно доброкачественный. AF экзомов: 0,0000013684; геномов: 0,0000065643.
- **rs115686643 (LARGE1)**. VEP: synonymous_variant (Tyr463=), аминокислота не меняется. ClinVar: конфликт - VUS (Illumina, 1★) / Likely benign (Labcorp, 1★). AF экзомов: 0,0000355719; геномов: 0,0000394374.
- **rs115706909 (SDF2L1)**. VEP: stop_gained (Arg74Ter), преждевременный стоп-кодон в транскрипте ENST00001093571.1. В транскрипте MANE Select ENST00000248958.5 замена синонимичная. В ClinVar записи нет; клиническая патогенность по этим данным не установлена. AF экзомов: 0,0000937443; геномов: 0,000696507.

## Заключение

ENTHD1 интересен сочетанием очень низкой частоты и вероятно доброкачественной классификации. У LARGE1 расходятся оценки лабораторий, а у SDF2L1 последствие зависит от транскрипта.

Эти примеры показывают ограничения аннотации: для LARGE1 нет согласованной оценки ClinVar, а для SDF2L1 нет записи в этой базе. Кроме того, одно выбранное последствие VEP не отражает различий между транскриптами.
